## Tasks
- A task sent for CD review locks its Assignees and Guardian too
- CD review is only possible when a Creative Director is set — "No CD set" otherwise
- The CD can approve some files and ask for changes on others, with a note each; approved files are kept for the next round
- Completed tasks are read-only for their 30 days (comments too); only Admins reopen them
- Files in a description or comment open for everyone who can see the task
- Copied text keeps its mentions and file chips when pasted into a comment or description

## Files and links
- Copy link on any file or Client Assets folder gives one short, branded download page; only Admins can turn a link off or on
- Each person gets their own link, and its page says who shared it
- Links never show up in Google or any search
- Photos load faster everywhere (smaller copies made once, HEIC always converted)

## Money
- The UAE dirham sign replaces AED on every amount
- Finance can add a claim by hand (this month or last), which then goes through HR approved and Paid as usual

## Content plans
- Counts and approving follow who the plan was sent to (Social Manager, CD or both)

## Mac app
- Liquid Glass sidebar; Admins can drag clients into a new order for everyone
- A client's colours as dots in its menu, like Finder's tags
