## E11 Console is now on the office server
- Open it at **console.e11hq.com** from any Mac, Windows PC or phone, in the office or outside
- Sign in with your work email: a one-time code is emailed to you, and you stay signed in for about a month
- Everyone sees changes **live**: new tasks, comments, notifications and files appear without refreshing
- Install it like an app: Safari → File → Add to Dock, or the Install button in Chrome/Edge
- Turn on desktop notifications in **My profile**
- If the internet drops, keep working: your changes are sent when you're back online
