## E11 Console for Mac
- A real Mac app: its own window and Dock icon, a menu bar, notifications with sound, and a red badge for unread notifications
- Uses the Mac file picker for attachments, saves downloads to your Downloads folder, and opens files in the right app
- Install it once: open **Terminal**, paste `curl -fsSL https://console.e11hq.com/install | bash` and press Return (or **your name → Get the Mac app**)
- It always shows the latest version of E11 Console, so you never need to reinstall for new features
