## Videos
- Every video gets a light 720p copy that starts playing straight away, also from outside the office. Download still gives the full-quality original
- Videos show a cover picture before they play

## Uploads and files
- An × next to every upload in progress cancels it
- Downloading a single file saves the file itself, not a .zip
- Files are removed from the server when their task or folder is deleted for good from the Trash. Final files in Client Assets are always kept, and so is a file still used somewhere else

## Phone
- Pop-up menus and sheets (a comment's long-press menu, a task's ⋯ menu) always show in full
- A task's dates sit on two lines, Start and Due, each with an × that's easy to tap
- The date wheel no longer fills in today by itself when it opens
- Client Assets client and folder pages fit the phone screen
- A flick on one page no longer keeps scrolling the next page
- No more Open in app button, which opened the bare file with no way back. Preview and Download cover it
- More room above the search box and the brand assets link
